部署到 GitHub · 操作指引

先把下面两个框填上，页面里所有链接和命令会自动跟着变。 每一步做完打个勾，进度会存在浏览器里，关了再开还在。
还没有账号？先到 github.com/signup 注册，免费。 仓库名建议用英文小写加连字符，它会成为你网址的一部分。

第 1 步 · 建一个空仓库

打开建仓库页面：github.com/new

  • Repository name 填你上面写的仓库名
  • 可见性选 Public（免费版只有公开仓库能开 Pages 网址）
  • 不要勾 Add a README / .gitignore / license —— 保持空仓库
  • 点 Create repository
为什么必须公开？GitHub 免费版的 Pages（免费网址）只支持公开仓库。 代码本身没什么可藏的；真正敏感的是你的监控名单，而那个已经在发布版里遮掉了 （workflow 里设了 PUBLISH_MODE=1）。API key 也放在 Secrets 里，不进代码。

第 2 步 · 把代码传上去

方式 A · 网页拖拽（不用碰终端，推荐先用这个）

  1. 点这个按钮打开已经准备好的文件夹：
  2. 把命令粘到「终端」里回车，Finder 会打开 上传用 文件夹
  3. 按 Command + Shift + .（三个键一起按）显示隐藏文件，你会看到多出一个 .github 文件夹 —— 这个是必须传的
  4. 全选（Command + A）→ 拖到仓库页面的上传区域 → 底部填一句说明 → 点 Commit changes

方式 B · 终端推送（以后改代码方便，但需要先建一个令牌）

  1. 建令牌：github.com/settings/tokens → Generate new token (classic) → 勾选 repo → 生成后复制保存（只显示一次）
  2. 把下面这段整体粘到终端，一路回车；提示输密码时粘贴那个令牌：
cd ~/USStockIntel
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git init
git add -A
git commit -m "init"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
两种方式选一个就行。方式 A 不需要任何认证配置，最省事； 方式 B 会在本机建一个 git 仓库，以后改完代码 git add -A && git commit -m "改了什么" && git push 就能同步。

第 3 步 · 配置 API Key（Secrets）

打开设置页：Settings → Secrets and variables → Actions

  • 点 New repository secret
  • Name 填 GLM_API_KEY（必须一字不差）
  • Secret 填你的智谱 key —— 就在项目里的 .env 文件里，GLM_API_KEY= 后面那串
  • 点 Add secret

可选：再加一个 SEC_USER_AGENT，值填 你的名字 你的邮箱。 不配也能跑（会用 config.yaml 里那个），但公开仓库建议配一个，免得邮箱被爬虫抓。

这个 key 千万不能写进代码或配置文件。 它现在只存在于本机 .env（已被 .gitignore 排除）和 GitHub Secrets 里，两边都不公开。

第 4 步 · 打开 Pages（免费网址）

打开设置页：Settings → Pages

  • Source 选 Deploy from a branch
  • Branch 选 main，右边目录选 /docs
  • 点 Save

保存后等 1～2 分钟，网址就能打开了 —— 上传的文件夹里已经带了一份 docs/index.html（今天的简报），不用等定时任务。之后云端每次跑完都会自动更新它。

第 5 步 · 手动跑一次

打开 Actions 页：Actions

  • 左边选 抓取美股公告
  • 右边点 Run workflow → 绿色按钮 Run workflow
  • 等 1～2 分钟，看到绿勾就是成功（点进去能看实时日志）

跑完后它会把新简报提交回仓库，Pages 需要再等 1～2 分钟构建。

如果这里没看到「抓取美股公告」这个 workflow，说明第 2 步的 .github/workflows/daily.yml 没传上去 —— 回第 2 步检查隐藏文件有没有显示出来。

第 6 步 · 打开你的简报网址

你的网址是：（填上用户名和仓库名后显示）

手机浏览器直接打开这个网址就行，可以「添加到主屏幕」当 App 用。

之后它会每 6 小时自动跑一次（北京时间 0:05 / 6:05 / 12:05 / 18:05）， 不需要你的电脑开着。GitHub 的定时任务可能延迟几分钟，正常现象。

可选 · 关掉本机的定时任务

云端跑起来之后，本机那个 launchd 定时任务就没必要了 —— 两边同时跑会各自维护一份数据库。

本机仍然可以手动跑：cd ~/USStockIntel && ./.venv/bin/python main.py
